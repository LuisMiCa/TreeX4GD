    Key features

    A clearer view of your Drive

    Browse folder structure, compare calculated folder totals, and save a snapshot of your Drive’s structure and metadata.

    Recursive folder mapping

    Map folders and their subfolders into a nested tree, with parent relationships preserved.

    Calculated folder sizes

    See how file sizes add up across your folder hierarchy.

    Export your way

    Export your scan as an interactive HTML tree, an Excel spreadsheet, or a reusable JSON metadata snapshot.

    Metadata-only, read-only

    Connects using Drive's read-only metadata scope. It never opens, edits, moves, or deletes a single file.

    Runs entirely on your machine

    Read metadata straight from Google Drive and build reports on your computer, with no third party in between.

    Stay in control of long scans

    Pause, resume, or stop long scans while TreeX4GD manages request limits and retries.

    The desktop app

    Built with Python. Made for your desktop.

    TreeX4GD combines a Python core with a Tkinter interface for scan controls, a live log window, and exports. To get started on Windows, macOS, or Linux, use the included launchers, which prepare the environment, install dependencies, and open the app.

    How it works

    From folder to report in four steps

    After installing Python and creating your Google OAuth credentials, follow four steps to build your first report.

    1. 1

      Launch the app

      Run the launcher for your OS and point it at your own Google OAuth credentials file.

    2. 2

      Choose your target

      Paste a folder URL or ID, or choose the root to scan your entire My Drive.

    3. 3

      Start the scan

      Sign in to Google when prompted, then monitor the scan in the log window. Pause, resume, or stop the scan as needed.

    4. 4

      Export

      Save the scan results as HTML, Excel, or JSON — ready to browse, analyze, or archive.

    To connect TreeX4GD to Google Drive, you’ll need your own Google Cloud project and OAuth credentials. The setup guide walks you through creating both.

    Export formats

    Browse in HTML. Analyze in Excel. Reuse with JSON.

    Explore the tree, compare file metadata, or create fresh reports from a saved snapshot.

    .html

    Interactive HTML report

    Open the report in your browser to browse the tree and search saved metadata.

    • Virtual scrolling for long file lists
    • Search by size or date (e.g., >10MB, <2023)
    • Expand/collapse entire folder levels
    • Direct, clickable links to Drive items
    .xlsx

    Excel spreadsheet

    Compare file sizes, dates, owners, and other collected metadata in a spreadsheet.

    • Frozen header and auto-adjusted columns
    • Folder paths, levels, and unique IDs
    • Visual hierarchy column
    • MD5 hashes where available
    .json

    Hierarchical JSON

    A portable snapshot of folder structure and collected metadata, ready to re-import offline.

    • Preserves nested folder relationships
    • Contains metadata, without file contents
    • Usable in scripts and automation
    • Generate reports without rescanning Drive
    Getting set up

    Get ready for your first scan.

    Prepare your computer, launch TreeX4GD, and connect to Google Drive.

    Download TreeX4GD Open setup guide
    1. 1

      Install Python

      Install Python 3.11 or newer. The setup guide covers any additional requirements for your operating system.

    2. 2

      Download and extract TreeX4GD

      Download the release archive for your operating system and extract it to a folder on your computer. The archive includes the source code and launchers.

    3. 3

      Run your launcher

      Open the extracted script/ folder and run the launcher for your operating system.

      Windows
      run_in_windows.bat
      macOS
      run_in_macOS.command
      Linux
      run_in_linux.sh

      The first launch prepares the Python environment and installs required packages automatically, so it can take a little longer.

    4. 4

      Connect Google Drive

      To let TreeX4GD read your Drive’s metadata, you’ll need your own Google Cloud project and OAuth credentials. Follow the setup guide to create them, then select the credentials JSON file in the app.

    Optional: build a standalone app

    Build an app that runs without Python installed on compatible computers with the same operating system and architecture. The setup guide covers preparation, build requirements, and instructions.

    Security

    Read-only access. Local reports.

    The app reads metadata directly from Google Drive and processes it on your computer.

    Local report processing

    TreeX4GD processes your Drive’s metadata locally on your computer and saves reports to a location of your choice.

    Read-only by design

    Requests Drive's drive.metadata.readonly scope only — it can't read file contents, edit, or delete anything.

    No saved sign-in tokens

    Session tokens stay in memory and aren’t saved to disk. They’re discarded when you close the app.

    Use your own credentials

    Connect to Google Drive using OAuth credentials from your own Google Cloud project, keeping access to your metadata under your control.
